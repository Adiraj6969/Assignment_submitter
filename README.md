
# Assignment Submission Tracker

## About the Project
The Assignment Submission Tracker is a simple web-based project developed to make assignment submission easier and more organized for students. It allows students to enter their personal details, select their course, subject and teacher, provide assignment information, and submit their assignments through a form.

## Features
- Student information form.
- Roll number and section input.
- Course selection dropdown.
- Subject selection dropdown.
- Teacher selection dropdown.
- Assignment name input.
- Date and time selection.
- Assignment file upload option.
- Submission success page.
- Simple and user-friendly interface.

## Technologies Used
- **HTML5** – Used to create the structure of the website.
- **CSS3** – Used to style the pages, forms, buttons and layout.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Fill in the required assignment details.
5. Click the Submit button.
6. The success page will appear.

## Project Objective
The main objective of this project is to understand the basics of HTML and CSS while creating a simple interface for assignment submission.
